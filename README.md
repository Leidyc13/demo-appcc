# Registro APPCC para obradores

Demo de una herramienta web para llevar el APPCC sin papeles en obradores y pymes alimentarias.

**Ver la demo:** https://leidyc13.github.io/demo-appcc/

## Qué incluye
- Control de temperaturas con alertas y acción correctiva obligatoria
- Plan de limpieza diario y semanal
- Recepción de materias primas con lote, caducidad y los 14 alérgenos (Reglamento UE 1169/2011)
- Lotes de producción que heredan los alérgenos de sus ingredientes
- Trazabilidad hacia atrás y hacia delante por lote
- Registro de incidencias e informes en CSV para inspección

Los datos son de ejemplo y se guardan solo en tu navegador.
